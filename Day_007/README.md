# Day 043 - Functional Programming

## Overview

Practiced advanced Python functions and functional programming techniques using an Employee Data Processor.

## Topics Covered

- Lambda Functions
- map()
- filter()
- reduce()
- List Comprehension
- Dictionary Comprehension
- sorted() with key
- Higher-order Functions

## Practical

The Employee Data Processor performs different operations on employee records.

### 1. Filter Employees

Used `filter()` with a lambda function to find employees whose salary is above 50000.

### 2. Transform Salaries

Used `map()` to increase employee salaries by 10%.

### 3. Find Highest Salary

Used `reduce()` to find the highest updated salary.

### 4. Sort Employees

Used `sorted()` with a lambda function as the key to sort employees according to their salary.

### 5. Comprehensions

Used list and dictionary comprehensions to create employee names and salary data.

## Key Concepts

### Lambda

A lambda is a small anonymous function used for simple operations.

### map()

`map()` applies a function to every item in an iterable.

### filter()

`filter()` selects items based on a condition.

### reduce()

`reduce()` combines multiple values into a single result.

### Higher-order Function

A higher-order function is a function that accepts another function as an argument or returns a function.

### List Comprehension

List comprehension provides a short way to create lists from existing iterables.

### Dictionary Comprehension

Dictionary comprehension provides a short way to create dictionaries from existing data.
