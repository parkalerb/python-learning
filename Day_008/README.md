# Day 050 - File Handling, JSON and API Data

## Overview

This project focuses on working with JSON data using Python.

The program reads user information from a JSON file, extracts required details from nested data, processes the information, and creates a new JSON report.

## Learning Objectives

- Read data from files using `open()`
- Work with JSON files
- Use `json.load()`
- Use `json.dump()`
- Access nested JSON data
- Process structured data
- Handle file and JSON-related exceptions
